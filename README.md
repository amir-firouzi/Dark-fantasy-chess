# ♟️ Dark Fantasy Chess v1.0.1

A 2D chess game built with **Python** and **Pygame**, featuring a dark fantasy atmosphere, custom chess pieces, multiple board themes, AI opponents, animations, and sound effects.

Dark Fantasy Chess aims to bring the classic chess experience into a darker visual world while keeping the gameplay familiar, accessible, and enjoyable.

---

## 🎮 Features

### ♟️ Gameplay
- Classic chess rules and gameplay.
- Local two-player mode.
- Play against an AI opponent.
- Multiple AI difficulty levels:
  - Easy
  - Normal
  - Hard
- Choose to play as White, Black, or Random.
- Legal move detection and move highlighting.
- Check, checkmate, and draw detection.
- Move history.
- Game duration tracking.

### 🎨 Visual Design
- Dark fantasy-inspired interface.
- Custom-designed chess piece assets.
- Multiple board themes.
- Smooth piece movement animations.
- Highlighting for selected pieces and legal moves.
- Special visual indicators for check and checkmate.

### 🔊 Audio
- Custom sound effects.
- Different sounds for normal moves.
- Check and checkmate sound effects.
- Sound effects can be enabled or disabled through Settings.

### ⚙️ Settings
- Sound effects toggle.
- Move animations toggle.
- Board theme selection.
- Fullscreen mode.
- Persistent settings.

### ⏸️ Game Controls
- Pause and resume gameplay.
- Restart the current game.
- Access settings during gameplay.
- View the final board position after a game ends.
- Review the result and move history.

---

## 🕹️ Game Modes

Currently, the game supports **Classic Chess**, with the standard chess rules and no time limit.

You can play Classic Chess in two ways:

- **Two Players:** Play locally with another player.
- **Vs AI:** Challenge the computer and choose your preferred difficulty.

## 🚀 Getting Started

### Requirements

- Python 3.10 or newer
- Pygame / Pygame-ce
- Git (optional, for cloning the repository)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amir-firouzi/Dark-fantasy-chess.git
   ```

2. Enter the project directory:

   ```bash
   cd Dark-fantasy-chess
   ```

3. Install the required dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Run the game:

   ```bash
   python src/main.py
   ```
